# AI 貼圖批次貼上 Preflight Checklist

> 開工前檢查一次，完工後用同一份清單自查。

## Non-scope

- 不修改後端 API、資料庫或正式環境。
- 不改變單筆欄位的生成資料結構，仍使用 `title` 與 `desc`。
- 不自動送出生圖請求。
- 不重構其他工具或共用元件。

## 功能與輸入解析（適用）

- [x] 每個非空白行使用第一個 `|` 分隔「標題」與「動作說明」。
- [x] 標題或動作說明為空時，不修改既有清單，並顯示繁體中文錯誤訊息與行號。
- [x] 忽略純空白行，並清除欄位前後空白。
- [x] 套用前明確告知會取代目前清單，避免意外覆蓋。
- [x] 沿用現有 40 筆上限，超過時不修改既有清單。
- [x] 套用成功後，筆數、預覽摘要與按鈕狀態同步更新。

## 前台表單與安全性（適用）

- [x] 批次內容只保留在瀏覽器記憶體，不新增網路傳輸或持久化。
- [x] 使用 `textContent` / input value 顯示使用者文字，不插入 HTML，避免 XSS。
- [x] 生成進行中停用批次套用，避免狀態競爭。
- [x] 錯誤訊息不洩漏 API key 或內部狀態。

## 無障礙與介面（適用）

- [x] 多行欄位有固定 label、格式說明與範例。
- [x] 按鈕文案明確表達「取代目前清單」。
- [x] 沿用既有 focus、disabled 與亮暗模式樣式。

## 測試（適用）

- [x] 正常解析兩筆 `標題|動作說明`。
- [x] 描述內再出現 `|` 時，只使用第一個分隔符號。
- [x] 空白行可忽略。
- [x] 缺少分隔符號、空標題、空說明時拒絕套用。
- [x] 超過 40 筆時拒絕套用。
- [ ] 既有單筆編輯與 OpenAI 模型清單測試維持通過。完整 `pytest` 因本機缺少依賴且 `uv` 發生系統函式庫 panic，未能執行；已完成 Python 語法、JavaScript 語法、批次解析行為與 diff 檢查。

## 不適用項目

- Schema、權限、個資、金錢、郵件、Webhook、跨服務副作用、時區、SSRF、第三方套件：本功能是既有靜態頁面的本機文字解析，不涉及上述範圍。
