01 使用方式

單次產生，不建立角色檔。主要／正面參考圖必填，其餘角度可提高同批一致性。

02 角色與貼圖風格

這裡的風格會同時套用於角色定稿圖與後續貼圖。請先選好，再產生角色定稿圖。

03 角色參考圖

圖片只在目前瀏覽器工作階段使用；產生時會經本站薄代理傳給所選 AI 供應商。上傳後統一轉為最長邊 1024px 的 PNG。

角色檔包含已上傳的原始照片與定稿圖，不含 API key。請妥善保管。

04 貼圖內容（一條 = 一張貼圖）
貼圖顯示文字 表情 / 動作描述

05 貼圖文字
整批文字風格

文字欄可用 Enter 手動分成最多兩段，AI 會依角色動作與留白自行決定上下、左右或對話框排版。批次貼上請用 \n 表示分段。

06 AI 服務
模型

API key 在站台「設定」面板統一管（右上齒輪），只存在你的瀏覽器；請求時經本站薄 proxy 轉給 AI 服務、用完即丟、不留存。生圖要錢、用你自己的 key。一組 8～24 張視模型 / 品質約 US$0.3～5。OpenAI 可能要求先到後台完成 API 組織驗證（platform.openai.com/settings/organization/general →「Verify Organization」）；若帳號暫時無法使用，可改用 Google。
